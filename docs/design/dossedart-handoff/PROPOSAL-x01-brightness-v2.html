X01 — fjern "mørk sky" + utvid active card + menu

Diagnose: Scanlines/vignette i ArcadeFrame er fine på home og setup fordi innholdet der er solid. I X01 cockpit er active-card-bakgrunnen (gradient alpha 0.10/0.02) og dartboard-segmentene (alpha 0.35) halvgjennomsiktige — scanlines blander seg ned i innholdet og resultatet er muddert.

Fix: ikke rør CRT-overlay. Bump alphas på X01-innholdet til solid nivå (samme palette, bare opasitet). Plus utvid active-card med AVG, og legg sound/memes/video/TTS i in-game-menyen.

  • Active-card bg: gradient(0.10, 0.02) → solid var(--surface) (#1a0030). Border + glow uendret.
  • Dartboard-segmenter: alpha 0.35 → 0.95. Magenta/cyan-paletten uendret.
  • Active-card content: AVG-stat lagt til (3-dart match average). LAST 3 + checkout vises som før.
  • Menu sheet: sound / memes / video / voice (TTS) lagt til som on/off toggles. Player Overview + Exit Match beholdt.
