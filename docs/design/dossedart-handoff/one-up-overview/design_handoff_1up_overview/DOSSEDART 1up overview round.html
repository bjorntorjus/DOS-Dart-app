1UP i X01-skjelettet — og hvem som bærer grønt og rødt.

Restyle på det godkjente X01-skjelettet (forslag B): samme 272px-sone, samme kortramme med spiller-accent, samme header og 300px-skinne. 1UP-data helles i: BEAT <target> som primærtall (SET THE TARGET i lime ved free throw), egne liv som ♥-pips, og skinnen i throw order med lives + ROUND OUT. Brief-ens ene spørsmål — hva bærer SAFE/CAN'T BEAT når rammen er identitet — får tre kandidater: A status-platen (anbefalt), B gløden, C primærtallet. Stress-states, full cockpit og fasit nederst.
