Statistikk · hub med 4 faner

Statistikk — profil, modus, heatmap, historikk.

Én hub vist på tvers av sine fire faner. Profil (landing) er hjertet: ELO + rangering, en seier-ring, rating-historikk-graf, per-modus seier% og head-to-head. Modus er ledertavle per spillmodus. Heatmap viser hvor pilene lander på brettet. Historikk lister siste kamper med ELO-endring.

All data kommer rett fra SavedPlayer / ModeStats / GameHistory. Samme arcade-chrome og farge-logikk som cockpit-ene (du = cyan, gull = topp, grønn/rød = ELO opp/ned). Spec-kortet kobler hver visning til datakildene.
