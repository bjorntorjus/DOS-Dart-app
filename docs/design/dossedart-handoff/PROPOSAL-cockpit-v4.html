X01 Cockpit V4 — name scaling

Tre cockpits side-om-side viser hvordan layouten håndterer kort, medium, lang og veldig lang navn.

  • Strategi: auto-shrink fontstørrelse i 3 trinn basert på navnelengde — 18px / 15px / 12px / 10px
  • Når navnet fortsatt ikke passer på 10px → ellipsis (...). Avatar+REMAINING må alltid være synlig.
  • Navnet vises alltid UPPERCASE for arkade-konsistens (følger DOSSEDART picker-tile-mønster)
  • Topbar-tittel ellipsizes også hvis nødvendig (f.eks. lange custom modes)
