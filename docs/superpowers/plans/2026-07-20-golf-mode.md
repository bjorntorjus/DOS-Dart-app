> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Golf game mode (DOSSEDART-only v1, rules v2 "darts-are-strokes"): 18 (or 9) holes played on numbers 1–18 in order; each hole ends on the first hit; strokes = hit value (T=1/D=2/S=3) + 1 per miss before it, three misses = 6; lowest total wins, sudden death on 19/20/Bull for 1st-place ties.

**Architecture:** Pure-Dart engine (`GolfEngine`, snapshot-undo like `OneUpEngine`) with Shanghai's round-based rotation (every player completes hole N before anyone starts N+1); own game screen reusing the shipped DOSSEDART cockpit chrome (CrtFrame/TopBar/ActionBar/menu/player-sheet) with new Golf widgets (active card, S/D/T input cells, scorecard strip + sheet); Shanghai's deferred-stats + post-game-undo protocol; setup via `DossedartSetupScaffold`.

**Tech Stack:** Flutter, no new packages. Fonts `PressStart2P`/`VT323` (already bundled).

```dart
/// Golf term for a hole's stroke score (1-6).
String golfTerm(int strokes) => const {
      1: 'ACE', 2: 'BIRDIE', 3: 'PAR',
      4: 'BOGEY', 5: 'DOUBLE BOGEY', 6: 'TRIPLE BOGEY',
    }[strokes]!;

class GolfDartResult {
  final bool wasHit;              // multiplier > 0
  final bool holeEnded;           // hit landed or 3rd miss
  final int? holeStrokes;         // 1-6, set when holeEnded
  final bool suddenDeathStarted;  // regulation just ended tied for 1st
  final bool playoffContinued;    // playoff hole resolved but still tied → next target
  final bool gameOver;
}

class GolfEngine {
  GolfEngine({required int playerCount, required int holes}); // holes: 9 | 18
  final int holes;

  // regulation state
  int currentHole;                // 0-based
  int currentPlayerIndex;
  int missesThisHole;             // current thrower's misses this hole (0-2)
  List<List<int?>> scorecards;    // [seat][hole], null = not played
  bool gameOver; int? winnerIndex; bool wonBySuddenDeath;

  // sudden death
  bool inSuddenDeath;
  int playoffHole;                // 0-based playoff round
  int get playoffTarget;          // const [19, 20, 25][playoffHole % 3]  (25 = Bull)
  List<int> playoffParticipants;  // seats still tied, seat order
  List<int?> playoffStrokes;      // length playerCount, null = not thrown this playoff hole

  // queries
  int get playerCount; int get activePlayerCount;
  int get holeNumber;             // currentHole + 1
  int get targetNumber;           // holeNumber, or playoffTarget in sudden death
  bool get canUndo;
  bool isSkipped(int i); Set<int> get skippedIndices;
  int total(int seat);            // regulation strokes so far (playoff excluded)
  int holesCompleted(int seat);
  int vsPar(int seat);            // total - 3 * holesCompleted
  List<int> placements();         // 1-based, tie-shared; skipped seats = 0 (Task 2)

  // per-seat stats (index-stable, grow on addPlayer)
  List<int> aces, bogeys, firstDartHits, dartsThrown; // bogeys counts strokes >= 4
  List<int?> bestHole;            // lowest hole score, null until first hole done

  // mutations
  GolfDartResult applyDart(int multiplier); // 0 = miss, 1 = S, 2 = D, 3 = T
  void undo(); void clearUndoStack();
  void addPlayer(); void removePlayer(int index);      // Task 3
}
```

Implementation notes:
- Snapshot undo (`_GolfUndoEntry` private class): deep-copy every mutable field (scorecards rows, stat lists, scalars, sudden-death state) before each `applyDart`, restore verbatim in `undo()`. This makes undo across hole/round/sudden-death boundaries free (spec §7). Model on `OneUpEngine`'s undo entry (`lib/models/one_up_engine.dart`).
- Rotation is Shanghai's (`lib/models/shanghai_engine.dart:109-134`): on hole end for the current thrower, `missesThisHole = 0` and advance to the next non-skipped seat; wrapping past the last seat increments `currentHole`; `currentHole == holes` → `_evaluateRegulationEnd()`. A safety-bounded while loop skips `_skipped` seats.
- `applyDart` scoring: `multiplier > 0` → `holeStrokes = (4 - multiplier) + missesThisHole`, record on scorecard + stats (`aces`/`bogeys`/`bestHole`/`firstDartHits` when `missesThisHole == 0 && multiplier == 3`… careful: **firstDartHits counts any hit with 0 misses**, aces counts strokes == 1), end hole. `multiplier == 0` → `missesThisHole++`; third miss → `holeStrokes = 6`, end hole. `dartsThrown[seat]++` on every dart. In sudden death write to `playoffStrokes` instead of the scorecard (Task 2).
- `_evaluateRegulationEnd()`: among non-skipped seats find lowest `total`; unique → `gameOver = true; winnerIndex = leader`; tie → Task 2's sudden death (until Task 2, set a temporary `gameOver = true; winnerIndex = null` and mark the tie-path test as covering Task 2 — simplest is to implement `_evaluateRegulationEnd` fully in Task 2 and keep Task 1's tests on non-tied games).

### Task 2: GolfEngine — sudden death + placements

**Files:**
- Modify: `lib/models/golf_engine.dart`
- Test: `test/models/golf_engine_test.dart` (extend)

**Interfaces:**
- Consumes: Task 1's engine.
- Produces: working `inSuddenDeath`/`playoffTarget`/`playoffParticipants`/`playoffStrokes`, `wonBySuddenDeath`, `placements()`.

Rules (spec §2/§7): tie for lowest after the final hole → tied leaders (only) play playoff holes on **19 → 20 → Bull → 19 → …**; same 3-dart/first-hit rules; unique lowest playoff stroke wins, tied-lowest continue to the next target, others drop out. Playoff strokes never touch `total()`. **Bull has no triple** (input offers S/D only; engine `assert(multiplier <= 2)` when `targetNumber == 25`). Sudden death resolves 1st only: the losing co-leaders share placement 2; everyone else keeps tie-shared placement by total.

`placements()` algorithm:

```dart
List<int> placements() {
  final act = [for (var i = 0; i < playerCount; i++) if (!isSkipped(i)) i];
  final out = List<int>.filled(playerCount, 0);
  for (final i in act) {
    out[i] = 1 + act.where((j) => total(j) < total(i)).length;
  }
  if (wonBySuddenDeath && winnerIndex != null) {
    for (final i in act) {
      if (i != winnerIndex && total(i) == total(winnerIndex!)) out[i] = 2;
    }
    out[winnerIndex!] = 1;
  }
  return out;
}
```

**Interfaces:**
- Produces: `addPlayer()`, `removePlayer(int index)`, index-stable `skippedIndices`.

Rules (spec §4.2/§7): an added player joins at the current hole with **every earlier hole recorded as par (3)**; a removed player's scorecard is kept (skipped-set pattern, list stays index-stable — Shanghai's `removePlayer`, `lib/models/shanghai_engine.dart:177`); a removed seat can never win; both operations `clearUndoStack()` (sibling convention). Removing down to one active seat ends the game with that seat as winner. class _GolfGameScreenState extends State<GolfGameScreen> {
```dart
  late final GolfEngine engine;
  late final List<Player> players;
  final GameAnnouncer _announcer = GameAnnouncer();
  final GameLogger _log = GameLogger.instance;
  final List<DartThrow> throwHistory = [];
  int _turnIdCounter = 0;
  final DateTime _gameStart = DateTime.now();

  @visibleForTesting
  GolfEngine get engineForTest => engine;

  @override
  void initState() {
    super.initState();
    players = List.of(widget.players);
    engine = GolfEngine(playerCount: players.length, holes: widget.config.holes);
    _announcer.init();
    _log.logGameStart(
      gameMode: 'Golf',
      playerNames: players.map((p) => p.name).toList(),
      playerScores: List.filled(players.length, 0),
      config: {'holes': widget.config.holes},
      build: kAppVersion,
    );
    _logTurn();
  }

  void _logTurn() {
    _log.logTurnStart(
      roundNumber: engine.holeNumber,
      playerIndex: engine.currentPlayerIndex,
      playerName: players[engine.currentPlayerIndex].name,
      score: engine.total(engine.currentPlayerIndex),
    );
    _log.logStandings(
      roundNumber: engine.holeNumber,
      names: players.map((p) => p.name).toList(),
      scores: [for (var i = 0; i < players.length; i++) engine.total(i)],
    );
    _log.log('H${engine.holeNumber} STATE target=${engine.targetNumber} '
        'sd=${engine.inSuddenDeath} misses=${engine.missesThisHole}');
  }

  void _onDartHit(int multiplier) {
    if (engine.gameOver) return;
    final seat = engine.currentPlayerIndex;
    final target = engine.targetNumber;
    final result = engine.applyDart(multiplier);
    throwHistory.add(DartThrow(
      playerIndex: seat,
      segment: multiplier == 0 ? 0 : target,
      multiplier: multiplier,
      points: multiplier == 0 ? 0 : target * multiplier,
      turnId: _turnIdCounter,
      roundNumber: engine.holeNumber,
    ));
    _announcer.announceThrow(
        multiplier == 0 ? 'miss' : '${target * multiplier}');
    setState(() {});
    if (result.holeEnded) {
      _turnIdCounter++;
      _handleHoleEnd(seat, result);
    }
  }

  void _onMiss() { /* copy 1UP _onMiss: play miss sound → _onDartHit(0) */ }

  void _handleHoleEnd(int seat, GolfDartResult result) { /* Task 8 fills; core: */
    if (result.gameOver) { _onGameEnd(); return; }
    _logTurn();
  }

  void _onUndo() {
    if (engine.gameOver) return;
    if (!engine.canUndo) return;
    setState(() {
      engine.undo();
      if (throwHistory.isNotEmpty) {
        final lastThrow = throwHistory.removeLast();
        _turnIdCounter = lastThrow.turnId;
      }
    });
    _log.logUndo();
    _announcer.announceGameEvent('Back');
  }

  void _onGameEnd() { /* Task 7 */ }

  // ---- card-state derivation ----
  GolfCardPhase get _phase {
    final done = _lastHoleStrokes;
    if (done != null) return done <= 3 ? GolfCardPhase.holeDoneGood : GolfCardPhase.holeDoneBad;
    return engine.missesThisHole == 0 ? GolfCardPhase.teeOff : GolfCardPhase.midHole;
  }

  int? _lastHoleStrokes; // set in _handleHoleEnd, cleared on next dart/undo (Task 8 wires the 1s display window alongside overlays)

  String get _statusLine {
    final done = _lastHoleStrokes;
    if (done != null) {
      return '${golfTerm(done)} — $done STROKE${done == 1 ? '' : 'S'}';
    }
    if (engine.missesThisHole == 0) {
      return engine.inSuddenDeath
          ? 'PLAYOFF — THROW AT ${engine.targetNumber == 25 ? 'BULL' : 'THE ${engine.targetNumber}'}'
          : 'TEE OFF — THROW AT THE ${engine.targetNumber}';
    }
    final left = 3 - engine.missesThisHole;
    return 'LYING ${engine.missesThisHole} — $left DART${left == 1 ? '' : 'S'} LEFT';
  }

  String get _holeLabel => engine.inSuddenDeath
      ? 'SUDDEN DEATH · ${engine.targetNumber == 25 ? 'BULL' : engine.targetNumber}'
      : 'HOLE ${engine.holeNumber} · PAR 3';
}
```

```dart
  final strokes = result.holeStrokes!;
  setState(() => _lastHoleStrokes = strokes);
  _resultTimer?.cancel();
  _resultTimer = Timer(const Duration(seconds: 1), () {
    if (mounted) setState(() => _lastHoleStrokes = null);
  });

  final phrase = switch (strokes) {
    1 => 'Ace! Hole in one!',
    6 => 'Triple bogey.',
    _ => '${golfTerm(strokes).toLowerCase()}!',
  };
  _announcer.announceGolf(phrase,
      soundFolders: ['golf/${golfTerm(strokes).toLowerCase().replaceAll(' ', '_')}']);

  if (result.gameOver) { _onGameEnd(); return; }
  if (result.suddenDeathStarted) {
    _announcer.announceGolf('Sudden death!', soundFolders: const ['golf/sudden_death']);
    setState(() => _overlaySuddenDeath = true);
    _overlayTimer?.cancel();
    _overlayTimer = Timer(const Duration(seconds: 1), () {
      if (mounted) setState(() => _overlaySuddenDeath = false);
    });
  } else if (result.playoffContinued) {
    _announcer.announceGolf('Still tied! Next hole: '
        '${engine.targetNumber == 25 ? 'bull' : engine.targetNumber}.');

  _announcer.announceNextPlayer(players[engine.currentPlayerIndex].name);

}
```
