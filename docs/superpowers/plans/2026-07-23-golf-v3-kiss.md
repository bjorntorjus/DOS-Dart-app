**Goal:** Evolve the QA-passed Golf cockpit v2 to the approved v3 KISS fasit — hero 244px with per-dart chips + status plate, leaderboard with scroll-past-5 and no THROWING column, 18-hole swipe strip, sudden-death chain in the strip zone, and ✗ MISS as a fourth console cell (ActionBar duplicate kept).

**Architecture:** Delta-based rewrite of the four golf widgets (`golf_hero`, `golf_leaderboard`, `golf_scorecard`, `golf_input_cells`) plus screen plumbing for per-hole dart labels (net-new data — today only a miss count exists). No engine/rules changes; the sudden-death overlay wiring in the screen's Stack stays intact.

**Fasit:** `docs/design/dossedart-handoff/golf-overview/design_handoff_golf_overview/golf-overview-round.jsx` (`Hero3`/`Plate3`/`Chip3`/`Board3`/`Strip3`/`Chain3`/`Console3`/`Cockpit3`) + `HANDOVER.md` (deltas D1–D6, cuts, budget). Round outcome (in the brief): MISS-in-console APPROVED **with the ActionBar duplicate kept**; hole number 120px APPROVED conditionally (tablet-verify; 244px hero fits a bump back to 130).

## Global Constraints

- Colors: `DossedartTokens` + white-alpha; player accents `dossedartAccent(index)`; **green = Golf mode brand** (`DossedartTokens.green`) — the hole number, console chrome. Term colors via existing `golfTermColor(strokes)`; zone-term mapping (chips/console cells): T/50 → ACE cyan, D/25 → BIRDIE green, S → PAR phosphor, miss → red.
- Fonts 'PressStart2P'/'VT323'; no borderRadius; English strings.
- **Zone budget fasit (rule 2 — nothing grows in-game):** `HERO 244` (fixed, incl. its 56px plate) · `LEADERBOARD 34 + 56×min(n,5) (+2 border)` · `STRIP/CHAIN 96` · `CONSOLE 220`. Hero margin `fromLTRB(16,14,16,0)`; leaderboard/strip/console margins `fromLTRB(16,12,16,0)` (console bottom spacing comes from the existing screen padding — adapt to the current Column, do not add the mockup's 100px chrome margin).
- Hero frame: 3px **player-accent** border (never flips with state); the plate carries state.
- `DART n/3` = dart being thrown (pips 11px per fasit).
- Cuts (must be GONE): hero TOTAL block, NOW THROWING/HOLE RESULT badge, leaderboard THROWING column, console footer caption `✗ MISS = +1 STROKE`, `H<n>` prefix on hole chips.
- Branch: `feat/overview-grammar`. `flutter analyze` clean before every commit (staged breaks only where a task says so).
